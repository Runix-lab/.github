# Contributing to Runix Lab's public resources

For profile or embodied-guide corrections, open an issue here. For AI4S course
content or labs, use the [course issue tracker](https://github.com/Runix-lab/ai4s-for-programmers/issues).
For filesystem code, follow [Runix FS contribution guidance](https://github.com/Runix-lab/runix-fs/blob/main/CONTRIBUTING.md)
and its development specifications.

Useful reports include the affected section/URL, what you observed, a primary
source supporting the correction, and a small runnable reproduction when relevant.
Do not include personal data, credentials or private customer material.

For new learning material, state the audience, prerequisites, learning outcome,
limitations and data provenance. Include commands and expected output. Label
synthetic examples and cite original papers or official documentation. Link to
third-party resources rather than copying material without permission.

Read the applicable resource license before submitting or adapting material.
Original contributions to the embodied learning guide are submitted under its
CC BY 4.0 license unless explicitly agreed otherwise. Contributions should be
reviewable and narrowly scoped; do not add unverifiable affiliations, credentials,
performance claims or promotional link lists.

Maintainers validate links and examples when changing the public profile. Publish
corrections in Git history rather than silently presenting estimates or upstream
results as Runix measurements. We do not guarantee an issue response deadline.
