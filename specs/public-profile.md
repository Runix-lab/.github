# Public organization profile contract

The public profile at `profile/README.md` represents Runix Lab, operated by
Runix AI Inc. Align product names and status with https://runixcloud.io.

- Lead with free learning resources and inspectable public repositories.
- Never link private repositories or publish internal operations as open source.
- Distinguish free reading, openly licensed material, software and commercial services.
- AI4S covers antibody/protein data, not all science; instruction is Chinese with
  an English overview. Content is CC BY-SA 4.0; code is MIT.
- The embodied guide is an original introductory reading/lab guide, not an
  established robotics curriculum, benchmark or hardware training course.
- Cite primary sources; third-party datasets retain their own terms.
- Label synthetic examples explicitly and do not invent learner counts,
  accreditations, partners, publications, performance or maturity.
- Explain correction/contribution routes without promising response deadlines.
- Validate public links, local links, example output and repository visibility.
- Every modification receives a Git commit. Backend APIs require unit tests;
  this profile change introduces no backend endpoint.

Sustain credibility through runnable examples, correction history, explicit
scope and maintained source attribution. Update the profile when actual content
changes; do not stamp a new review date without checking its claims and links.
